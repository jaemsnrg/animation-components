# Cosmos Study

A monochrome, image-first design system. Everything here is generated from one source of truth.

```
tokens.json (DTCG)  ──►  scripts/build-tokens.mjs (Style Dictionary)
                              ├─ dist/tokens.css          CSS variables, light/dark
                              ├─ dist/tailwind.theme.css  Tailwind v4 @theme
                              └─ dist/dictionary.json     token → CSS var → Tailwind utility
```

- **Foundations** previews colours (both themes), type, spacing, radius, shadows and motion, using the generated Tailwind utilities.
- **Components** are [shadcn/ui](https://ui.shadcn.com) components (React + Radix + Tailwind) in `src/components/ui`, restyled to the Cosmos look. shadcn's variables (`--primary`, `--muted`, `--border`, …) are bound to the tokens in `src/styles/globals.css`, so dark mode and token changes flow through. The `components/*/README.md` files are the original design specs.
- Use the **Theme** toolbar to switch light/dark; stories set `data-theme` on their own wrapper.

## Tailwind naming

Utilities mirror token names, so semantic colours read `bg-bg-primary`, `text-text-secondary`, `border-border-primary`.
Type styles are `text-body`, `text-heading-large`; add `font-mono` for the `mono` style. Radius, shadow and easing use `rounded-*`, `shadow-*`, `ease-*`;
spacing keys match Tailwind's scale (`p-4` = `space-4`), with layout tokens as `h-layout-header-height`.

## Commands

```
npm run tokens:check   # validate tokens.json against the DTCG spec (Terrazzo)
npm run tokens:build   # regenerate dist/
npm run storybook
```
